2. Найди проблемные участки поля по фото

Порог "здоровой зелени":
Здоровые посевы0%
Проблемные зоны0%
Решение-
Как это работает 
# Фото поля с дрона - это сетка пикселей (R, G, B)
здоровых = 0
for пиксель in фото:
    r, g, b = пиксель
    индекс = 2*g - r - b   # "индекс зелени" ExG
    if индекс > порог:
        здоровых += 1

процент = здоровых / len(фото) * 100
print(f"Здоровых посевов: {процент:.0f}%")

Растения отражают много зелёного света, а сухая трава и земля - больше красного. Поэтому формула 2G - R - B "подсвечивает" живые растения. Агрономы используют похожие индексы (например, NDVI с инфракрасной камерой), чтобы заранее найти, где посевам плохо.
